JWT (JSON Web Token) is a compact, URL-safe token format used for securely 
transmitting information between parties as a JSON object. It is commonly used 
for authentication and authorization in web applications.

**Components of JWT:**
1. **Header**: Specifies the token type (JWT) and signing algorithm (e.g., HS256).
2. **Payload**: Contains the claims (user data and metadata).
3. **Signature**: Ensures the token’s integrity and authenticity by signing the header and payload with a secret or private key.

**Why is the signature used?**  
The signature prevents tampering. If the header or payload is altered, the signature will not match, so the server can detect invalid or malicious tokens.
